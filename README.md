# ShopEase - E-Commerce Storefront 🛒

ShopEase is a responsive e-commerce frontend application built using React.js.  
It allows users to browse products, view detailed product information, and manage their shopping cart with global state management.

## 🚀 Features

- Responsive e-commerce UI
- Product listing using Fake Store API
- Dynamic product categories
- Category-based filtering
- Product details page
- Add products to cart
- Global cart management using Context API
- Increase/decrease product quantity
- Remove products from cart
- Dynamic cart item count
- Total cart price calculation
- Loading states while fetching data
- Responsive design for desktop and mobile

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router DOM
- Tailwind CSS
- Context API
- JavaScript (ES6+)

### API
- Fake Store API

API URL:
https://fakestoreapi.com/
